# Tasarım referansları

Sahibin sağladığı referanslar. Bunlar görsel yön ve
`packages/shared/src/design` içindeki değerler için yetkilidir (authoritative).

## Perfect UI (T1'den itibaren ürünün tek tasarım dili)

- `perfectui-overview.png`: Perfect UI'ın kendi tanıtım görseli (2880x2048).
  Butonlar, rozetler, kartlar, form alanları, açık/koyu mod anahtarı, mesaj
  listesi, zaman çizelgesi ve fiyat kartı; ürünün web paneli, süper admin
  paneli, herkese açık sayfaları ve daha sonra mobil uygulaması bu görünümü
  izler.
- `perfectui-overview-thumb.png`: aynı görselin küçük hali (önizleme için).

Kaynak: https://perfectui.dev, npm `@chrissgon/perfectui` 1.0.0 (MIT lisansı).
Kitin Figma dosyası (README'deki bağlantı) hem ticari hem kişisel projelerde
ücretsiz kullanılabilir. Tasarım sisteminin kendisi, token'lar ve bileşen
eşlemesi için bkz. `docs/TASARIM.md`.

## Diğer referanslar

Ek referans eklenecekse (örneğin Mobbin, Refero, Mariana Tek / Momence üye
uygulamalarından ekranlar) Perfect UI dilinin içinde kalan akış ve yerleşim
örnekleri olarak eklenir; renk, köşe ve yazı tipi her zaman Perfect UI
token'larından gelir.

Adlandırma: `<alan>-<ekran>-<kaynak>.png`, örneğin `mobile-booking-momence.png`.
Gerçek müşteri verisi içeren ekran görüntüleri eklemeyin.
